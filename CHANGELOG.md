# Historial de cambios

Este proyecto sigue [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-07-16

### Añadido

- Interfaz de escritorio para seleccionar, optimizar y guardar documentos PDF.
- Perfiles conservador, equilibrado y máximo verificado.
- Generación de múltiples candidatos de compresión.
- Validación de páginas, geometría, texto, anotaciones, formularios, marcadores y adjuntos.
- Comparación visual completa mediante SSIM, MAE y PSNR.
- Informes JSON de validación.
- Interfaz de terminal.
- Instaladores para Windows x64 y macOS Apple Silicon.
- Construcciones reproducibles con PowerShell, Docker, Wine y GitHub Actions.
